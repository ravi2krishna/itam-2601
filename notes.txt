    -> What Is Hardware Asset Management (HAM)         

        -> Hardware Asset Management (HAM) is the Management of your Physical Assets.

            -> From When An Asset is Requested 

                -> Then Procured 

                    -> Then Eventually Being Retired and Disposed Of 

            -> HAM Ensures your Physical Assets are Fully Tracked 
            
            -> HAM Ensures also involves in Managing Warranties, Contracts and 
            Vendor Agreements. 

            -> Without HAM in place, it would be hard to figure out 
            what assets the company owns and what assets employee owns.

            -> Without HAM, Where the Assets are Located ? 

            -> Without HAM, it's hard to Understand what asset supports 
            which business service or system. 

            -> Without HAM, we have security concerns, who is using this asset 
            from security and accountability standpoint.

    -> Configuration Items 

        -> A Configuration Item (CI) is a component that is managed
        in order to deliver an IT Service. 

        -> Configuration Items are stored in CMDB
        Configuration Management Data Base 

        -> Configuration Items Consists Of Hardware, Softwares,
        Services etc 

        -> Tracking Configuration Items is important practice 
        in any organization as it allows top track Upstream and 
        Downstream Dependencies for components that supports
        your IT Services.

        -> Configuration Items Contains all the Configuration Information
        relating to CI's. For Example HP-Z9 Workstation is a computer which 
        can include Information such as Hard drive capacity, RAM capacity,
        it's IP Address, it's MAC Address, Installed Softwares etc 

        -> NOTE: In servicenow, when you create an hardware asset, 
        a Configuration item record is also created and linked to it.

            -> If an Asset class is defined at the Model Level 
            when creating a Configuration item, then a hardware asset will be created. 

            
                    Asset                           Configuration Item 
                HP-Z9 Workstation                   HP-Z9 Workstation
                (Asset Tag)                         (HDD-RAM-IP)

            -> NOTE: In Most Of the organizations, Configuration items are tracked 
            by the Configuration management teams(ITOM), as Configuration items 
            needs to be tracked and monitored to ensure availability of business services.

            -> NOTE: IT Asset Management Team tracks the "Financial and Physical Lifecycle"
            Of Assets. 

        
        -> Difference Between Asset and Configuration Item 

            -> Asset is a device like computer or server, but needs to tracked 
            due to it's Financial value to an organization.

            -> Whereas Configuration Item Can also be assets, but not always, and is 
            tracked as it directly affects one or more business services.
            For Example, a Configuration File is CI but not an Asset.

        
        -> Asset                                    -> Configuration Item (CI)

            -> Tracked For Financial Purpose            -> Tracked For Supporting Business Services 

            -> Tracked From Acquisition To Disposal     -> Only Tracked When It's In Use 

            -> Has Parent / Child Relationships         -> Has Upstream and Downstream Dependencies 

            -> A Financial Value Is Assigned            -> No Financial Value Is Assigned

            -> Tracked By IT Asset Manager              -> Tracked By Configuration Manager

    -> Asset Depreciation 

        -> What Asset Depreciation Means 

        -> Calculate Depreciation Of Assets 

        -> Different Depreciation Methods 

    -> Asset Depreciation is the process followed by organizations
    to allocate the cost of an asset over the duration of its useful life.

    -> This Process is typically fulfilled by "Accounting & Finance" Teams.

    -> To Calculate Depreciation Of An Asset, we need following Information 

        -> Useful Life: This is the amount of time (years) the asset is 
        typically useful for, for an example a laptop is typically useful for 5 years. 

        -> Total Price: Total Amount the organization pays for the asset. 

        -> Purchase Date: Date the asset was procured from the vendor. 

        -> Depreciation Method: Formula Used For Calculating the Depreciation

        -> Salvage Value: Amount the asset will be worth, when it's fully Depreciated. 

    
    -> Depreciation Methods 

        -> Straight Line (SL)

        -> Double Declining Balance (DDB)


    -> Straight Line (SL)

        -> is the most common Depreciation methods, as the cost of the asset 
        is allocated equally over the useful life of an asset. 

        -> Taking Laptop as an example, an organization purchases a laptop 
        for $1000, and it'll be Depreciated over a useful life of 5 years,
        and it's Salvage value is $50 

        -> Calculating Yearly Depreciation Of this Laptop Using Straight Line (SL)

            -> Depreciation Amount = Subtract Salvage value from purchased value 
            then divide by useful life in years 


    -> Double Declining Balance (DDB) 

        -> NOTE: In Double Declining Balance methods the assets lose most 
        of their values in their first years. 

        -> NOTE: Taking an Mobile Phone as an example, they typically lose 
        their value about 30-40% in the first year itself. 

        -> Calculating Double Declining Balance (DDB) 

            -> Depreciation Amount = 100% of The Asset Value / 5 Times 2 

        -> Taking Laptop as an example, an organization purchases a laptop 
        for $1000, and it'll be Depreciated over a useful life of 5 years,
        and it's Salvage value is $50 

    
    -> NOTE: The Key Difference Between Straight Line and Double Declining Balance
    is that in Double Declining Balance Method we never include Salvage Value.
